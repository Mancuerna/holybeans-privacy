Empieza por el síntoma y comprueba el paso correspondiente antes de cambiar tus datos.

No encuentro un café o una preparación

Borra la búsqueda, revisa los filtros y consulta los archivados. Si archivaste un café, sus preparaciones activas también quedaron archivadas. Recupera el café para volver a trabajar con él.

Si el problema comenzó tras una restauración, comprueba la fecha y procedencia de la copia. Guarda el diario actual antes de restaurar otro archivo.

Las existencias no coinciden

Comprueba el lote, las porciones congeladas y las dosis de las últimas preparaciones. Disponible y congelado son cantidades distintas. Archivar una preparación no devuelve su consumo.

Para registrar lo que has pesado realmente, utiliza Ajustar existencias → Corrección por pesada. Para un regalo o pérdida, elige su motivo. Consulta la guía de existencias antes de corregir.

El dispositivo no aparece o no da lecturas

  1. Comprueba que el modelo está admitido por tu versión y que tiene batería.
  2. Enciéndelo cerca del móvil y desconéctalo de otras apps y teléfonos.
  3. Revisa Bluetooth y los permisos de dispositivos cercanos que pide Android; algunas versiones antiguas requieren ubicación para buscar.
  4. Vuelve a buscar desde Ajustes y comprueba si llegan lecturas.

Si conecta pero no actualiza el peso, anota el modelo y firmware. No todos los firmwares tienen el mismo comportamiento. Puedes seguir registrando pesos manualmente. Para fallos de impresión, sigue esta comprobación antes de repetir el trabajo.

Drive no termina o el otro móvil está distinto

Los móviles mantienen diarios independientes. Para recuperar el de otro dispositivo debes seleccionar y restaurar una copia; no hay fusión automática.

Si falla una copia, comprueba conexión y cuenta, vuelve a la pantalla de Drive y pulsa Crear copia ahora. Comprueba la fecha de la última copia completada. Mientras tanto, puedes usar el diario y exportar un ZIP.

Si Google rechaza la autorización, conserva una copia local y comunica el mensaje de error. No borres el diario para intentar arreglar la conexión.

Faltan fotos después de recuperar datos

Comprueba si restauraste un ZIP completo o un JSON sin imágenes. Las copias internas solo pueden volver a enlazar las fotos que sigan en el teléfono. Si conservas un ZIP con fotos, guarda antes el estado actual y utiliza ese archivo para la recuperación.

Pide ayuda con el contexto necesario

Indica la versión de HolyBeans desde Ajustes → Acerca de, versión de Android, pasos realizados, resultado esperado y mensaje que aparece. Para dispositivos, añade modelo y firmware si lo conoces.

Si envías una captura, oculta nombres, cuentas, direcciones y notas personales. No adjuntes contraseñas, claves, identificadores Bluetooth ni una copia completa de tu diario para una consulta inicial.
