# HolyBeans public website

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Spanish- and English-speaking HolyBeans users who need help recording coffee,
understanding their inventory, connecting equipment and protecting their journal.

## Product Purpose

Explain how to use the Android app through an original, task-based user guide.
The requested reference is the organization of Beanstats documentation, with
HolyBeans' own content and its existing visual identity.

## Capabilities and Constraints

GitHub Pages, static HTML and local CSS. Keep the current domain and privacy
URLs. Keep both languages aligned. No analytics, forms, remote fonts or new
runtime dependencies. Examples are fictional; private journals, photos,
identifiers, diagnostics and internal operational documents are never assets.
Explain device support with its actual experimental limitations.

## Brand Commitments

HolyBeans and CaffeinatedDev. Preserve the existing bean/halo mark, brown accent
and warm neutral surfaces. Plain, practical wording using the app's labels.

## Evidence on Hand

Existing public pages and app UI/source reviewed for behavior. The public guide
uses original prose and explicitly illustrative examples. No app screenshots
are included in this first edition.
