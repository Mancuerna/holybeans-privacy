Cupping sessions

Compare several cups, save your impressions and revisit the session.

On this page

  • Set up two to six cups
  • Follow the phases
  • Run a blind cupping
  • Finish and revisit

Set up two to six cups

Open Equipment → Methods and tap Start in the Cupping row. Choose the number of cups and an optional session name. The same coffee can appear in several cups.

Set a shared dose, water amount and temperature. Choose a common grinder, setting and water profile or adjust them per cup. For a regular session, select each cup's coffee and lot or frozen portion.

Check that there is enough coffee for all cups. A draft does not deduct stock.

Follow the phases

  1. Review reminder times and tap Start and pour water.
  2. Mark the corresponding step after breaking the crust and skimming the foam.
  3. Let the cups cool and begin tasting when the temperature allows you to evaluate them.
  4. Rate each cup and add notes that help distinguish it.

Times are editable guides. The timer can be paused or reset per phase and resumes when you return. Sound reminders work while the cupping screen is open and respect the device's silent mode.

Run a blind cupping

Enable Blind cupping when setting up the session. Cups use letters and are scored before coffees are assigned.

Confirming ratings fixes the scores and notes. Then assign a coffee and stock source to each letter. Incomplete identification remains a draft without consuming stock.

Finish and revisit

Answer the overall rating and five intensities for each cup. You can choose Not evaluated; leaving a field Unanswered keeps it pending. Overall ratings run from 0 to 10 and intensities from 1 to 5. These are personal ratings, not SCA quality scores.

Choosing Finish cupping saves each cup as a brew and consumes its dose. Revisit it in Cupping sessions and check which notes you include before sharing.
